# 치료체험후기 관리자 기능

관리자 사이드바의 **치료체험후기 관리**에서 회원과 관리자가 등록한 후기를 함께 관리합니다.

## 관리 기능

- 진료 과목 필터, 제목·본문 검색, 최신순·오래된순 정렬, 페이지 이동을 지원합니다.
- 관리자 화면에서 새 후기를 등록하고 상세 확인, 수정, 삭제할 수 있습니다.
- 삭제 전 확인창을 표시하며, 삭제하거나 교체한 관리 대상 이미지도 함께 정리합니다.
- 기존 일반 텍스트 후기와 새 서식 후기 모두 표시하고 검색할 수 있습니다.

## 편집기와 이미지

- 글자 크기·색상·형광펜·정렬·목록·링크 등 병원소식과 같은 서식 편집기를 사용합니다.
- 본문에 이미지를 붙여넣거나 끌어놓을 수 있고, 첨부 이미지의 대표 지정·순서 변경·삭제가 가능합니다.
- 본문과 첨부를 합쳐 최대 10개, 파일당 10MB이며 JPG/PNG/WEBP/GIF를 지원합니다.
- 이미지는 `reviews` 버킷의 `admin-reviews/{후기 ID}/{임의 파일명}` 경로에 관리자 서명 업로드로 저장합니다.

## 홈페이지 연동

- 메인 치료후기 영역은 `reviews` 테이블의 최신 후기 최대 12개를 등록일 역순으로 표시합니다.
- 회원 전용 본문은 메인에 노출하지 않고 공개 목록에도 표시되는 제목과 등록일만 사용합니다.
- 기존 더미 후기는 사용하지 않으며 작성자 아이디도 표시하지 않습니다.
- 관리자 또는 회원이 후기를 등록·수정·삭제하면 메인과 후기 목록 캐시를 즉시 갱신합니다.
